# Security

Paceboard is a local, single-user application. It does not provide authentication
for publicly exposed services. Keep its ports bound to loopback.

Report vulnerabilities using GitHub's private vulnerability reporting on this
repository's Security tab. Do not post credentials or personal health data in a
public issue. If private reporting is unavailable, open an issue requesting a
private contact channel without including exploit details or sensitive data.

Include the affected version, reproduction steps using synthetic data, and the
impact. There is no guaranteed response time. If you exposed provider credentials,
revoke them with the provider and reconnect; deleting them from a file is not
sufficient.
